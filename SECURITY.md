# Security Policy

## Supported Versions

Version 1.0.0 is the initial public release of 3db.

Security issues will be evaluated individually. A fixed security-update
schedule or maintenance period has not been established.

## Reporting a Vulnerability

Please avoid disclosing sensitive vulnerability details in public issues.

If GitHub private vulnerability reporting is enabled, use that channel.

Otherwise, request a private contact channel without publishing
exploit details, credentials, or private project data.

## Data Safety

3db manages local project files, metadata, and an SQLite database.

Create independent backups before testing changes involving imports,
migration, versioning, backup, or recovery.

Do not delete or modify user data as part of troubleshooting without
first creating a verified backup.
