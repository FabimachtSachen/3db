# 3db 1.0.0 – First Release

**Release date:** November 7, 2026

The first public release of 3db introduces a local desktop workspace for managing personal 3D printing projects.

## Highlights

- Project management and organization
- STL, 3MF, image, and document imports
- Project variants and file associations
- Version snapshots and change detection
- Search and filtering
- Customizable interface with light and dark themes
- Local SQLite-based data management

## Quality assurance

Before release, 3db underwent regression testing, file integrity and recovery testing, backup/restore validation, and manual acceptance testing in a Windows 11 virtual machine.

The final Windows installer passed installation, branding, startup, and existing-test-data checks.
