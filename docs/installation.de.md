# Installation von 3db

## System

3db 1.0.0 ist für Windows x64 vorgesehen.
Die finale Abnahme erfolgte in einer Windows-11-Testumgebung.

## Installation

1. Lade den Installer aus dem offiziellen GitHub-Release herunter.
2. Prüfe die SHA-256-Prüfsumme anhand der Release Notes.
3. Starte die Installationsdatei.
4. Öffne 3db und richte deine Projektbibliothek ein.

## Aktualisierung

Erstelle vor einem Versionswechsel eine unabhängige Sicherung
deiner Projektbibliothek.

Das Upgrade von 0.9.8 auf 1.0.0 wurde erfolgreich getestet.
Für andere frühe Entwicklungsstände besteht keine allgemeine
Kompatibilitätsgarantie.

## Fehlerbehebung

Lösche bei Installations- oder Startproblemen keine vorhandenen
Datenbanken oder Projektordner.

Bewahre bestehende Daten und Sicherungen auf, bevor du weitere
Schritte zur Fehlerbehebung durchführst.
