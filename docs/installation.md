# Installation

## Requirements

- Windows x64
- A user-writable location for the project library

## Install

1. Download the Windows installer from the official GitHub release.
2. Verify its SHA-256 checksum against the release notes.
3. Run the installer.
4. Launch 3db and configure your project library.

## Updating

Back up your project library before installing an update.

An update from version 0.9.8 to 1.0.0 was tested successfully during the release acceptance process.

Other historical upgrade paths are not automatically guaranteed.

## Troubleshooting

If the application does not start or an update fails, preserve the existing project library and backup files.

Do not delete database or project files as a troubleshooting step.
