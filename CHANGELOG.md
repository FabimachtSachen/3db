# Changelog

Notable changes to 3db are documented here.

## [1.0.0] - 2026-11-07

### First Release

The first public version of 3db.

### Features

- Local project creation, editing, and archiving
- Managed project folders and file imports
- Support for STL, 3MF, images, and PDF documents
- Search, tags, categories, and project filters
- Project variants and file associations
- File change detection and version snapshots
- Customizable project overview
- Light, dark, and system themes

### Reliability

- Import and recovery safety tests
- Database migration and integrity tests
- Backup and restore validation
- Windows installer upgrade verification
- Manual Windows 11 virtual-machine acceptance tests

### Packaging

- Windows x64 NSIS installer
- Updated 3db application icon and branding

## Development milestones

Before version 1.0.0, the application underwent multiple internal prototype, integration, migration, and security-testing iterations.

These development builds are not presented as separate public releases.
